# 🚚 J&T Express UAE — AUH South West Operations Hub

Automated operations tracking, attendance, courier performance, staff complaints score, operations monitoring (Arrival -> Dispatch -> Delivered -> Signing Rate %), and Google Sheets sync for J&T Express Abu Dhabi South West Station.

---

## 🚀 1-Click Deploy to Vercel:

1. Push this repository to your GitHub account (e.g. `jnt-auh-hub`).
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New Project"** > **"Import"** your `jnt-auh-hub` repository.
4. Framework will automatically be detected as **Vite**.
5. Click **Deploy**!
6. In ~45 seconds, your dashboard will be live with a permanent `.vercel.app` URL!

---

## 💻 Local Development:

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

The app will run at `http://localhost:3000`.

---

## 📦 Build for Production:

```bash
npm run build
```

---

## 📊 Google Sheets Sync:
1. Open the live dashboard.
2. Click **"Live Google Sync"** in the top bar.
3. Paste your Google Sheet URL.
4. Click **"Sync Now"** — all tabs, dropdowns, and KPI formulas will automatically populate in your Google Sheet!
